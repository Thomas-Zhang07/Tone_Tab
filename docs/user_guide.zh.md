# Tone_Tab 快速使用说明

## 第一次打开

1. 点右上角 **“音频设置…”**。
2. 选声卡（优先 ASIO）、吉他输入通道、缓冲区 64–128。
3. 用力扫弦，输入峰值到 −12 ~ −6 dB 比较合适；CLIP 灯亮就把声卡增益调小。

## 音色页

- 预设栏保存 / 读取整条链。预设文件是 ASCII 文件名，显示名称存在 XML 里，中英文都有。
- 单击踏板开关；双击打开参数；拖动换顺序；右键可以换模型、复制、删除。
- **“+ 添加效果”** 可以加内置效果、NAM 箱头、箱体 IR、VST3 插件。
- NAM 模型默认按 48 kHz 训练；不是 48 kHz 时程序会自动重采样。名字里带 *Cab* / *full rig*
  的模型已经带箱体，不要再加 IR；只有箱头的模型后面接箱体 IR。
- 鼓机在下方。音色页按空格开始 / 停止。**Humanize** 让力度有点变化；**Auto Fill**
  每 2 / 4 / 8 小节自动加花。

## 练习谱面

- 打开 `.gp3`–`.gp5`、`.gpx`、`.gp`，也可以把文件拖进窗口。
- 选音轨、调速度、设 A-B 循环，然后播放。
- **示范音** 用改进后的拨弦合成器播放当前音轨，其他音轨当伴奏；**鼓机** 不会被效果器处理。
- **弹奏判定** 默认开启：Perfect / Good / 错音 / Miss。第一次用先做 **“延迟校准…”**。
- **等待模式** 弹对才往下走。**速度阶梯** 连续弹稳后自动提速。

## 录音

- **录音** 会在 `我的文档\Tone_Tab\recordings` 下建一个录音文件夹：
  - `mix.wav`：吉他 + 效果器 + 鼓机 + 伴奏（立体声）
  - `dry.wav`：输入增益之前的干吉他（单声道）
  - `take.json`：谱子、音轨、速度、循环、预备拍和同步位置
- **回放…** 会拿干声走现在的效果器链，所以可以换音色重新听；旧的单声道录音也能回放。

## 快捷键

| 按键 | 功能 |
| --- | --- |
| 空格 | 播放 / 暂停 |
| ← / → | 上 / 下一小节 |
| Home | 回到开头 |
| A / B | 设循环起点 / 终点 |
| ↑ / ↓ | 加速 / 减速 |
| W | 等待模式 |
| N | 音名开关 |

## 文件位置

- 设置：`%APPDATA%\Tone_Tab\settings.xml`
- 预设：`我的文档\Tone_Tab\presets`
- 录音：`我的文档\Tone_Tab\recordings`
- 练习记录：`%APPDATA%\Tone_Tab\practice_log.json`
- 音色库：程序旁边的 `assets\`（只在本机，不放进远程仓库）
