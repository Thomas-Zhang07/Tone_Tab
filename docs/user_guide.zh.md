# Tone_Tab 快速使用说明

## 第一次打开

1. 点右上角 **“音频设置…”**。
2. 选声卡（优先 ASIO）、吉他输入通道、缓冲区 64–128。
3. 用力扫弦，输入峰值到 −12 ~ −6 dB 比较合适；CLIP 灯亮就把声卡增益调小。

## 音色页

- 预设栏保存 / 读取整条链。预设文件是 ASCII 文件名，显示名称存在 XML 里，中英文都有。
- 单击踏板开关；双击打开参数；拖动换顺序；右键可以换模型、复制、删除。
- **“+ 添加音色 / 效果”** 打开音色菜单：
  - **Fender NAM**：直接列出音色库里的 Fender 采样。
  - **浏览 NAM 模型…**：带搜索和分类（清音 / 轻失真 / 高增益 / 推子 / A2 带箱体 / 精选）的模型浏览器，共 270 个。
  - **加载 NAM 箱头模型…**：文件选择。
  - **加载箱体 IR…**，然后是内置效果分组和 VST3。
- 预设下拉框最上面是 **Fender NAM**、**Mayer**、**Classic Rock** 和 **真实采样**，
  Gervana 已经移到后面。
- NAM 模型默认按 48 kHz 训练；不是 48 kHz 时程序会自动重采样。名字里带 *Cab* / *full rig*
  的模型已经带箱体，不要再加 IR；只有箱头的模型后面接箱体 IR。
- 顶部 **“鼓机”** 标签是独立的鼓机页：大号开始 / 停止、可见的风格网格
  （摇滚/流行、律动、金属/蓝调/爵士、蓝调/灵魂乐、其他）、带播放头的 16 步节奏格、
  主歌 / 副歌 / 加花、自动加花、速度 / 打拍、摇摆、人性化、鼓音量，以及
  鼓件音量（底鼓、军鼓、镲片、通鼓、吊镲）。空格也可以开始 / 停止。
- 想自己编节奏，选 **Custom（自定义）**；点其他风格的格子会先复制成自定义再编辑。
  左键点格子开关音符，**Shift+点击**是重音，**Alt+点击**是鬼音，右键清掉该格；
  **编辑：主歌/副歌/加花** 选择段落，**清空** 清掉整段，改动会自动保存。
  主歌和副歌每小节都用同一个节奏，加花只在小节轮到加花时播放。

## 循环站（顶部标签）

- **空格** 开始录音；再按一次结束循环，循环马上开始播放。播放中按 **空格**
  准备好叠加录音（从循环起点开始），再按一次结束叠加。**停止** / **Esc** 停止播放，
  **清除** 删除循环。
- 开始和结束默认 **对齐到：小节**，所以空格按早按晚都没关系：
  - 按**早**了：会继续录到小节线再结束；
  - 按**晚**了：会自动修剪回小节线。
  也可以选 **拍** 做更短的循环，或选 **关** 完全自由。
- 鼓机在播放时，录音会从下一小节鼓点开始，循环一直跟鼓对齐。想要最稳的效果，
  先开鼓机再录；切换到其他标签页后循环仍会继续放。
- **新循环长度** 可以是 **自动**（再按一次结束），或固定 1 / 2 / 4 / 8 小节。
  固定长度只需按一次空格，录完自动开始循环。
- **循环** 轨道显示这次循环的波形、小节编号和播放头；**实时** 轨道显示你现在
  正在弹的内容（还没开始录音时也会显示）。
- 速度和鼓机共用。循环最长 30 秒。

## 练习谱面

- 打开 `.gp3`–`.gp5`、`.gpx`、`.gp`，也可以把文件拖进窗口。
- 选音轨、调速度、设 A-B 循环，然后播放。
- **示范音** 用改进后的拨弦合成器播放当前音轨，其他音轨当伴奏；**鼓机** 不会被效果器处理。
- **弹奏判定** 默认开启：Perfect / Good / 错音 / Miss。第一次用先做 **“延迟校准…”**。
- **等待模式** 弹对才往下走。**速度阶梯** 连续弹稳后自动提速。

## 录音页（顶部标签）

顶部 **“录音”** 标签是专门的录音页：波形时间线、录音、录音列表、回放、删除、刷新、
打开文件夹。练习页里的“● 录音 / 回放…”也还能用，方便边看谱边录。

- 选中一次录音会读取它的波形（回放用的干声）。**点波形就从那个位置开始回放**；
  回放中再点任意位置可以跳过去。**拖动**可以选择一段区域（右键取消选区）。
- **播放 / 暂停 / 停止**：播放从播放头继续（没有位置时从头开始）；暂停保留播放头；
  停止回到开头。**空格** 切换播放 / 暂停。播放头跟着回放走。
- **完整混音（关 = 干声）** 切换回放内容：
  - **开**：播放录音的 `mix.wav` —— 吉他 + 效果器 + 鼓机 + 伴奏 + 循环，和你录的时候一样。
  - **关**：干声走**当前**效果器链（重新过音色）。
  默认开启。两种模式下时间线显示的都是干声；补录只作用于干声路径。
- 录音列表显示日期、长度，以及是否和谱子同步。
- **录音时**，时间线会显示最近 15 秒的实时输入波形（`LIVE INPUT`），右边是录音头。
- **补录选区**：拖出一段区域，点 **补录选区**。会有 2 秒预备，进入选区后旧音频静音，
  你听到的是自己新弹的；到选区结尾自动停止。补录以片段形式存放在这次录音的
  `clips/` 文件夹，并写进 `take.json`，原来的 `mix.wav` / `dry.wav` 不会被修改。
  时间线上的蓝色“PUNCH”带表示补录层；同一段再补录会覆盖（后面的片段优先）。
- **导出 WAV…**：选 **重过效果器（当前链）** 会把整段录音连同所有补录过一遍当前效果器链
  导出；**干声 DI** 导出未处理的单声道；**完整录音混音（不含补录）** 直接导出原来的
  `mix.wav`（吉他 + 效果器 + 鼓机 + 伴奏 + 循环，录的时候是什么就导什么，补录不应用到这个模式）。
  导出的是整段，不是选区。

- **录音** 会在录音文件夹下建一个录音文件夹（默认
  `我的文档\Tone_Tab\recordings`；在录音页点 **“更改文件夹…”** 可以换到别处，
  例如 `E:\guitar_audio\recordings`）：
  - `mix.wav`：吉他 + 效果器 + 鼓机 + 伴奏（立体声）
  - `dry.wav`：输入增益之前的干吉他（单声道）
  - `take.json`：谱子、音轨、速度、循环、预备拍、同步位置和补录片段列表
  - `clips/`：非破坏性补录片段（只有补录过才有）
- **回放…** 会拿干声（连同补录层）走现在的效果器链，所以可以换音色重新听；旧的单声道录音也能回放。

## 快捷键

| 按键 | 功能 |
| --- | --- |
| 空格 | 练习页：播放 / 暂停 · 录音页：播放 / 暂停 · 鼓机：开始 / 停止 · 循环站：录音 / 结束 / 叠加 |
| Esc（循环站） | 停止循环 |
| ← / → | 上 / 下一小节 |
| Home | 回到开头 |
| A / B | 设循环起点 / 终点 |
| ↑ / ↓ | 加速 / 减速 |
| W | 等待模式 |
| N | 音名开关 |

## 文件位置

- 设置：`%APPDATA%\Tone_Tab\settings.xml`
- 预设：`我的文档\Tone_Tab\presets`
- 录音：`我的文档\Tone_Tab\recordings`
- 练习记录：`%APPDATA%\Tone_Tab\practice_log.json`
- 音色库：程序旁边的 `assets\`（只在本机，不放进远程仓库）
